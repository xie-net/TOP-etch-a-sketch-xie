# TOP-etch-a-sketch-xie
New etch-a-sketch like project to demonstrate DOM manipulation with javascript
1. Create a webpage with a 16x16 grid of square divs using javascript
2. Create a container div for the grid. [done]
3. Use a hover effect to change the color when the mouse passes over a square on the grid, leaving a trail. (changes stat, not temporary)

Hint- you can add or change class to change the color or state of the div, change background color

4. Create a button that does a pop up to ask the user for number of squares per side for new grid. existing grid removed, new grid populates.

LIMIT 100

EXTRA: 

1. Rainbow grid
2. Darken each square until it reaches maximum after 10 hovers.
